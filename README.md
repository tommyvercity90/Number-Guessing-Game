# 🎯 Number Guessing Game

A fun and interactive **Number Guessing Game** built using HTML, CSS, and JavaScript. The player tries to guess a randomly generated secret number between 1 and 100 and receives hints indicating whether the guess is too high or too low.

## ✨ Features

- 🎲 **Random Number Generation** – Generates a random number between 1 and 100.
- 📈 **Higher/Lower Hints** – Guides players toward the correct answer.
- 🔢 **Attempt Counter** – Tracks the number of valid guesses.
- ✅ **Input Validation** – Accepts only whole numbers within the specified range.
- 🔄 **Play Again** – Restart the game with a new secret number.
- 🎨 **Modern UI** – Clean interface with gradient backgrounds and smooth hover effects.
- 📱 **Responsive Design** – Works on desktop, tablet, and mobile screens.
- ⚡ **Instant Feedback** – Displays messages immediately after each guess.

## 🛠️ Technologies Used

- **HTML5** – Structures the game interface.
- **CSS3** – Provides styling, layout, animations, and responsiveness.
- **JavaScript** – Handles random number generation, game logic, validation, and attempt tracking.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```
git clone https://github.com/your-username/number-guessing-game.git
```

Replace `your-username` with your GitHub username and use your actual repository URL.

### 2. Navigate to the Project Folder

```
cd number-guessing-game
```

### 3. Run the Project

Open `index.html` in your preferred web browser.

Alternatively, open the folder in Visual Studio Code and use the **Live Server** extension.

No additional libraries or dependencies are required.

## 🎮 How to Play

1. Open the game in your browser.
2. Enter a whole number between 1 and 100.
3. Click **Check Guess** to submit your guess.
4. Read the hint displayed on the screen:
   - 📈 **Too low!** Try a higher number.
   - 📉 **Too high!** Try a lower number.
   - 🎉 **Correct!** You found the secret number.
5. Check your attempt count.
6. Click **Play Again** to start a new round.
